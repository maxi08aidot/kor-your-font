npx skills add maxi08aidot/kor-your-font

사진만 주고 AI와 만들기

글자 순서를 직접 입력하지 않아도 됩니다. AI가 사진의 필체를 확인하고, 결과 미리보기까지 함께 검수합니다.

  1. Codex 또는 Claude Code에 스킬을 설치합니다.
  2. 필체 사진을 넣고 “한글 필체 폰트로 만들어줘”라고 요청합니다.
  3. 부분 폰트는 사진 한 장으로, 전체 한글 폰트는 67자모 워크시트 두 장으로 만듭니다.

어떻게 만들어지나요

1 쓰기

진한 펜을 들고 종이에 글자를 쓰세요. 어떤 종이든 좋습니다. 냅킨도 괜찮아요. 글자끼리 닿지만 않게 써주세요.

2 찍기

위에서 휴대폰으로 한 장이면 됩니다. 그림자도, 비스듬한 각도도, 공책 스프링도 알아서 처리합니다. 스캐너도, 정확한 양식도 필요 없습니다.

3 /kor-your-font 실행

Claude Code에 사진을 끌어다 놓고 스킬을 불러주세요. 글자를 찾아 라벨을 붙이고, 초·중·종성을 조합해 폰트를 만들고, 결과까지 확인해 줍니다.

AI 없이도 됩니다

이 스킬은 시스템 의존성이 전혀 없는 평범한 npm CLI 위에 얹혀 있습니다. 무엇을 썼는지만 알려주면 나머지는 혼자 다 합니다:

# 한글 자유 필기 사진, 쓴 순서 그대로 (부분 폰트):
npx kor-your-font make-korean note.jpg --chars "안녕하세요Hello" --name "My Note"

# 현대 한글 11,172자 전체 폰트는 한글 워크시트로:
npx kor-your-font template-korean -o korean-template.pdf
npx kor-your-font make-korean-full page-1.jpg page-2.jpg --name "My Hangul Hand"

# 영문만 필요하면:
npx kor-your-font make photo.jpg --chars "ABCabc" --name "My Hand"
